# Data Structures and Algorithms

This repository is my C++ workspace for rebuilding DSA fundamentals and progressing toward independent LeetCode problem solving.

The study sequence follows the GeeksforGeeks DSA curriculum. The full syllabus, repository map, progress checklist, and problem-solving workflow are in [COURSE_STRUCTURE.md](COURSE_STRUCTURE.md).

## Repository layout

The numbered directories follow the course order:

- `00-foundations/` — C++ fundamentals, STL, and modules

- `03-searching-sorting/`
- `04-hashing/`
- `05-linked-lists/`

- `10-greedy/`

## Cleanup

Remove generated Windows executables recursively with:

```text
mingw32-make clean
```

The examples remain independent C++ programs so they can be compiled and studied one at a time.
